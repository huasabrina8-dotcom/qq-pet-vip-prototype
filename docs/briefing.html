1. 一句话

萌宠乐园是挂在菲盘式 VIP 冲档上的情感养成：用户大约每 24 小时回来深度抚养一只菲律宾神话神兽，用照料推动形态成长，从而提高登录粘性。

2. 产品目的（Locked）

目的提高登录粘性，让用户更频繁进站
手段约每 24 小时回来做一轮深度抚养，参与神兽成长

3. 玩家手册

以下用玩家口吻。开发 / 测试按此核对入口、按钮和说明文案。

这是什么

萌宠乐园是你的神兽小窝。领养一只菲律宾神话神兽，大约每 24 小时回来照料一轮，它才会慢慢长大。VIP 决定最高能养到哪一档，升 VIP 不会立刻换装。照料全部免费，不能买卖宠物。

从哪进

入口你能做什么
大厅看钱包、领每日返水、做每日任务；点「去照看」进宠物窝
VIP看等级、XP、返水；也可去宠物窝、更换神兽
宠物窝选神兽、每日照料、和萌宠对话、看成长、点进化、看今日排名

手机底栏：大厅｜VIP｜宠物。电脑从大厅侧栏或「宠物窝」进入。

第一次来

第一次进宠物窝必须选一只本命神兽，不能跳过。六选一：彩羽神鸟 · 月食神龙 · 山林精灵 · 吉兆灵鸟 · 海之仙女 · 树精守护神。选完从幼宠开始养。之后可随时换，新神兽继承已经养成的形态。

每天怎么养

  1. 进宠物窝，点 饱食 / 喝水 / 清洁。想吃、想玩、想喝时，对应照料一次即可。
  2. 完成今日深度抚养：抚摸 ×3、对话 ×1、喂食 ×2。对话在宠物窝「对话」页签。
  3. 同一天可以多照料几次；大约 24 小时后再来一轮深度抚养。
  4. 背包每天有免费补给，没有购买。本日对应照料完成后，「使用」显示「本日已达标」不可点。
  5. 顶栏耳机或右下角绿色按钮打开在线客服（演示，不产生真实工单）。

超过大约 24 小时没来，亲密度可能下降，大厅会提醒「去照看」。VIP 等级不会掉。

神兽怎么长大

幼宠 → 银徽 → 管家 → 金甲 → 翼宠 → 冠宠。每一档要养够抚养日 + 照料次数；进度满了且 VIP 够时，点 进化。

舞台旁能看到下一形态。图鉴里已养成的档可以回顾；还没养到的档只能看说明，不能假穿。养满了但 VIP 不够，进化会提示去冲档。

换神兽

随时可换，不收费。换了还是原来那一档，进度还在。不能卖掉，也不能解绑。一人始终一只。

大厅每日任务

每天各做一次，可增加 VIP XP：登录 +50 · 领返水 +40 · 访 VIP +40 · 看视频 +60

常见问题

问答
升了 VIP，神兽怎么还没变？正常。形态只跟照料和进化走，不跟 VIP 跳档。
为什么进化是灰的？本档抚养日或照料次数还没满，或 VIP 还不够下一档。
一天只能点一次吗？不是。同一次来可以多照料；深度抚养大约每 24 小时一轮。
几天没来会掉 VIP 吗？不会。最多亲密度下降，回来继续养即可。
宠物窝要充值才能养吗？不要。照料和背包补给都免费。

4. 宣讲主线

  1. 为什么做：粘性。不是再做一个充值玩法。
  2. 每天回来干什么：深度抚养一轮（摸、说、喂），神兽才会长。
  3. 长什么样：六种菲律宾神兽，同种六档；靠养，不靠升 VIP 瞬间变身。
  4. VIP 干什么：冲档卖点页 + 成长上限。VIP3 最多养到金甲。
  5. 换神兽：随时可换，继承当前形态档，不解绑、不收费。
  6. 养到头：冠宠后发五选一礼物（非充值）。
  7. 双端：PC 与 H5 同一套规则；H5 按手机重排。

6. 宠物窝规则（摘要）

  • 绑定：始终绑定 VIP。无出售、无解绑。换神兽 ≠ 解绑。
  • 当日抚养：饱食 / 喝水 / 清洁 + 四条状态（0–100）。更多互动全免费。
  • 主动需求：想吃 / 想玩 / 想喝；满足后安静 24h。
  • 亲密度 vs VIP：24h 无互动可能降亲密度，不降 VIP。
  • 进化：本档抚养日 + 互动都满、且 VIP 够上限才可点；点完形态 +1。
  • 下一形态：舞台旁始终预览；冠宠后显示已达终极。
  • 图鉴：已养成档看回顾，未养成档看解锁说明，不能假穿。
  • 背包：每日免费补给。没有购买按钮。本日对应照料达成后，「使用」不可点，提示本日已达标。

8. 定稿界面

PC 宠物窝：左舞台与抚养进度，右图鉴 + 照料 / 对话 / 排名。不要出现已绑定橙章、装饰云、身份区重复积分条。

H5：舞台铺满；下一形态贴右上；三颗大抚养按钮；养成进度合成一张卡。底栏大厅｜VIP｜宠物。页签含对话。

大厅与宠物窝可打开在线客服演示窗（非真工单）。好友帮养规则仍在，当前定稿页签不露出帮养。

10. 测试验收清单

A. 红线

  • 找不到游戏厅、转入转出、一键回收
  • 找不到庄园 / 种田 / 出售宠物
  • 宠物窝没有付费购买
  • 只有六种神话神兽，没有猫狗
  • 抽奖玩法不出现

B. 选种与换种

  • 第一次进窝强制选种，关不掉
  • 换种后形态档不变
  • 换种不收费、不解绑

C. 抚养与进化

  • 未满进度时进化灰色
  • 本档抚养完成后可进化，形态 +1
  • VIP3 不能进翼宠；升 VIP 不会立刻换装

D. 24h 与 VIP 任务

  • 模拟经过 24 小时后亲密度可降，VIP 不变
  • 同一次访问可连续照料多次
  • 领返水、充值演示不改变宠物形态

E. 终极奖励与双端

  • 五选一文案含「非充值」；同品种不能领两次
  • PC / H5 同域共享进度
  • 对外项目名是萌宠乐园

11. 演示脚本

  1. 重置演示 → 进宠物窝 → 选彩羽神鸟 → 看舞台与下一形态「银徽」。
  2. 点饱食 / 喝水 / 清洁。
  3. 「本档抚养完成」→ 进化 → 形态变为银徽。
  4. 更换神兽为月食神龙 → 仍是银徽档。
  5. 大厅领返水、做一条每日任务。
  6. VIP 页切换立绘风格，确认不换档。
  7. 「演示 VIP5 终极奖励」→ 五选一是礼物不是充值。
  8. H5 用 390 宽走同一遍。
