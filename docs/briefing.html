1. 一句话

萌宠乐园是挂在菲盘式 VIP 冲档上的情感养成：用户大约每 24 小时回来深度抚养一只菲律宾神话神兽，用照料推动形态成长，从而提高登录粘性。

它不是游戏厅、不是庄园种田、不是卖宠物、不是抽奖。

2. 产品目的（Locked）

目的提高登录粘性，让用户更频繁进站
手段约每 24 小时回来做一轮深度抚养，参与神兽成长
深度抚养抚摸 ×3 + 对话 ×1 + 喂食 ×2，完成后可领成长奖励
时间轴滚动 24h，从上次抚养互动起算
同一次访问允许多次互动；禁止做成「24 小时只能点一次」
缺席亲密度可能降级（提醒回来）；不降 VIP

3. 明确不做（测试不要按这些出 bug）

下列全部 Out of Scope，出现即视为做错需求。

不做说明
游戏厅 / 厅网格不把 XP 绑到「喂厅」
转入 / 转出 / 一键回收不做资金划转玩法
宠内付费墙宠物窝无充值、无内购、无付费道具
终极奖励当充值冠宠奖励是发给用户的五选一礼物
VIP庄园 / 种田已砍掉
出售宠物 / 解绑已砍掉；一员一宠始终绑定
猫、狗等现实宠物只有菲律宾神话神兽
抽奖同站另一项目
暗黑霓虹赌场风必须白橙亮厅

大厅顶栏「充值」只做 VIP / 钱包演示，不驱动养宠。

宠物窝

H5 底栏固定三 Tab：大厅 | VIP | 宠物。

5. 宣讲主线（建议 8 分钟）

  1. 为什么做：粘性。不是再做一个充值玩法。
  2. 每天回来干什么：深度抚养一轮（摸、说、喂），神兽才会长。
  3. 长什么样：六种菲律宾神兽，同种六档；靠养，不靠升 VIP 瞬间变身。
  4. VIP 干什么：冲档卖点页 + 成长上限。VIP3 最多养到金甲。
  5. 换神兽：随时可换，继承当前形态档，不解绑、不收费。
  6. 养到头：冠宠后发五选一礼物（非充值）。
  7. 双端：PC 与 H5 同一套规则；H5 按手机重排。

6.3 立绘风格

中性 / 神圣 / 可爱 / 墨金 / 玄祀 / 暮金。VIP 页可按当前穿着档随时换，不付费。最终留哪几套后定。

7. 宠物窝规则（摘要）

  • 绑定：始终绑定 VIP。无出售、无解绑。换神兽 ≠ 解绑。
  • 当日抚养：饱食 / 喝水 / 清洁 + 四条状态（0–100）。更多互动全免费。
  • 主动需求：想吃 / 想玩 / 想喝；满足后安静 24h。
  • 亲密度 vs VIP：24h 无互动可能降亲密度，不降 VIP。
  • 进化：本档抚养日 + 互动都满、且 VIP 够上限才可点；点完形态 +1。
  • 下一形态：舞台旁始终预览；冠宠后显示已达终极。
  • 图鉴：已养成档看回顾，未养成档看解锁说明，不能假穿。
  • 背包：每日免费补给。没有购买按钮。
  • 终极奖励：每品种一次五选一（₱88 / ₱188 / 亲密度礼包 / 今日积分 / 双倍亲密度），非充值。
  • 口吻：需要抚养时中文撒娇；不需要时正向抚慰，不凶。

9. 定稿界面

PC 宠物窝：左舞台与抚养进度，右图鉴 + 照料 / 排名。不要出现已绑定橙章、装饰云、身份区重复积分条。

H5：舞台铺满；下一形态贴右上；三颗大抚养按钮；养成进度合成一张卡。底栏大厅｜VIP｜宠物。

对话、帮养规则仍在，当前定稿页签只露出照料与排名。测试主路径以露出界面为准。

双端规则同一套；原型共享 state.js / vip_butler_pet_v3

11. 测试验收清单

A. 红线

  • 找不到游戏厅、转入转出、一键回收
  • 找不到庄园 / 种田 / 出售宠物
  • 宠物窝没有付费购买
  • 只有六种神话神兽，没有猫狗
  • 抽奖玩法不出现

B. 选种与换种

  • 第一次进窝强制选种，关不掉
  • 换种后形态档不变
  • 换种不收费、不解绑

C. 抚养与进化

  • 未满进度时进化灰色
  • 本档抚养完成后可进化，形态 +1
  • VIP3 不能进翼宠；升 VIP 不会立刻换装

D. 24h 与 VIP 任务

  • 模拟经过 24 小时后亲密度可降，VIP 不变
  • 同一次访问可连续照料多次
  • 领返水、充值演示不改变宠物形态

E. 终极奖励与双端

  • 五选一文案含「非充值」；同品种不能领两次
  • PC / H5 同域共享进度
  • 对外项目名是萌宠乐园

12. 演示脚本

  1. 重置演示 → 进宠物窝 → 选彩羽神鸟 → 看舞台与下一形态「银徽」。
  2. 点饱食 / 喝水 / 清洁。
  3. 「本档抚养完成」→ 进化 → 形态变为银徽。
  4. 更换神兽为月食神龙 → 仍是银徽档。
  5. 大厅领返水、做一条每日任务。
  6. VIP 页切换立绘风格，确认不换档。
  7. 「演示 VIP5 终极奖励」→ 五选一是礼物不是充值。
  8. H5 用 390 宽走同一遍。
