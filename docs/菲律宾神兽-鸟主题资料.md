|----|------|
| 形态档 | 幼宠 → 银徽 → 管家 → 金甲 → 翼宠 → 冠宠（0–5） |

| 终极奖励 | 该品种达冠宠后 **每品种一次** 自选礼（非充值） |
| 视觉 | Juan365 白橙亮厅；友好神兽，非恐怖向 |
