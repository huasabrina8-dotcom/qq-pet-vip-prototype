# VIP管家宠 · 冲档版 — 需求说明

> C 端可点击原型 · 对应目录 `c-end/`  
> 视觉参照 Juan365 Lobby / VIP Level（白灰底 + 橙 Deposit + 绿 Claim + 蓝 Banner）  
> 产品骨架锁定：**VIP 冲档 + 管家宠养成 + Light C（Daily Tasks）**  
> 原名「厅厅管家宠」已更名为「VIP管家宠」，避免暗示游戏厅功能。

---

## 0. 产品目的（Locked · 登录粘性）

| 项 | 说明 |
|----|------|
| **目的** | **提高用户粘性** / 更频繁登录进站 |
| **手段** | 每 **24 小时**回来对神话神兽做一次 **深度抚养**，参与成长 |
| **深度抚养** | = 既有「今日抚养任务 / 亲密度任务」：抚摸×3 + 对话×1 + 喂食×2 → 可领亲密度礼包（+ 少量 VIP XP） |
| **节奏** | 滚动 24h，自上次抚养互动 `lastInteractAt` 起算；与亲密度保护窗、需求 24h 满足窗对齐 |
| **同访自由** | **不**限制 24h 内只能点一次；同一次访问可继续多互动；养成习惯是「约每 24h 回来做一轮深度抚养」 |
| **留存叙事** | 保护倒计时 + 需求再出现 + 今日深度抚养进度 + 下一形态；缺席 → 亲密度降级（既有规则）表述为 **提醒回来**，非纯惩罚 |
| **神兽口吻** | 需要抚养：按当前形态 **Taglish lambing** 撒娇（sige na / please naman / miss na kita / haplos / kain na / ha，不用中文「嘛呀」腔）；不需抚养进页：菲律宾信仰习惯抚慰（Ingat / Bathala / suwerte，正向不凶） |
| **API** | `TTStore.getNurtureCadenceInfo()` / `getPetSnapshot().nurtureCadence`（status: `fresh` \| `due_soon` \| `due` \| `overdue`）；口吻 `getPetVoiceInfo()` / `getPetSnapshot().voice` |

## 1. 范围（Scope）

### 1.1 In Scope

| 模块 | 说明 |
|------|------|
| 主钱包 P / G | 大厅 Header 展示；Deposit / Claim 落点为 P |
| 管家宠 HUD | 等级徽章 + 距下一级剩余 XP；点击进宠物窝 |
| **宠物窝 / 养成页** | QQ宠物式：照料 + **主动需求(想吃/玩/喝)·24h 满足** + **24h 抚养节奏（登录粘性）** + **下一形态预览** + **抚养步进进化** + 今日积分/排名 + 帮养 + 对话 + 亲密度保护 + VIP 绑定（无出售） |
| VIP Level 页 | 橙状态卡、档位轮播（含管家宠形态预览）、**六套立绘风格切换**（中性/神圣/可爱/墨金/玄祀/暮金，当前档随时换、不付费；最终留哪几套后定）、返水%、Benefits / Guide / Rewards；**已绑定管家宠**入口 |
| Daily Tasks | 登录 / 领返水 / 访 VIP / 看视频 / 照料宠物 |
| Cashback Claim | Lobby 侧栏绿色 Claim（演示）+ XP |
| Deposit 演示 | Header 橙色按钮：+₱ 与少量 XP |
| 升级庆祝 | XP 跨档时简单弹窗 |
| Demo +XP | VIP 页冲档演示按钮 |

### 1.2 Out of Scope / 非本需求

- **游戏厅 / 厅磁贴 / 平台划转（转入 / 转出 / 一键回收）— 明确不在本 C 端需求内**
- 真实充值 / 提现 / 支付通道
- 真实客服工单与发奖
- 后台 Admin（现有根目录 `index.html` 管理端原型保持不动）
- 多币种切换、真实对账
- 暗黑霓虹赌场风视觉；不把 Admin 页改成 C 端大厅
- 服务端持久化（本原型仅 `localStorage`）
- **VIP庄园 / 种田经营**（已砍掉，不做）
- **出售宠物 / 出售解绑 / 售后再养**（已砍掉，不做）

## 2. 产品骨架（Locked）

### VIP管家宠（冲档吉祥物 + 情感养成）

- **P**：主钱包，Deposit / Claim / 买道具 的落点
- **宠 HUD**：展示当前 VIP 等级与升档剩余 XP；入口「去照看」
- **宠物窝**：QQ宠物式照料循环，补足情感互动，**不替代** VIP Level 卖点页
- **XP** 来自：Daily Tasks、领返水、Deposit 演示、照料宠物、VIP 页 Demo +XP

### VIP Sell A — Juan365 VIP Level

- Tier：`VIPxs`（如 VIP3s）
- Level：`VIPn`（如 VIP3）
- 展示：XP 进度、Cashback Rate、Max
- Tabs：VIP Benefits · VIP Guide · Rewards
- 权益领取：**Claim Via Support**（弹窗演示）

### Light C — Daily Tasks

- 仅提供**额外 XP**，支撑冲档演示
- 每自然日各任务可完成一次

## 3. 核心流程

```
Lobby
  ├─ 查看 P / G / 宠 HUD / VIP 进度条
  ├─ 宠 HUD「去照看」→ 宠物窝（养成互动）
  ├─ Claim Daily Cashback → P ↑ +XP（可完成「领返水」任务）
  ├─ Deposit 演示 → P ↑ +XP
  ├─ Daily Tasks（登录 / 访 VIP / 看视频 / 照料宠物）→ +XP
  ├─ Watch & Earn 卡 → 完成观看任务
  └─ Bonus Mission 卡片 → VIP Level 页
        ├─ 状态卡宠徽章 /「去照看」→ 宠物窝
        ├─ 状态卡 / 轮播 / 返水
        ├─ Benefits → Support 领取弹窗
        ├─ Guide（规则与 XP 表）
        ├─ Rewards
        └─ Demo +XP → 可冲档升级庆祝

宠物窝（情感养成，互补 VIP）
  ├─ 首次进入新手引导（可跳过）
  ├─ VIP 绑定徽章 + 菲律宾神兽品种（首次必选）+ VIP 形态画廊
  ├─ 照料 / 对话 / 好友帮养 / 今日排名（无出售）
  ├─ 亲密度 24h 冻结保护（超时降亲密度，不降 VIP）
  ├─ 24h 抚养节奏卡（深度抚养进度 · 下次建议回来 · 留存提醒）
  └─ 链回 VIP Level / Lobby
```

### 4.4 宠物状态与道具（演示）

| 项 | 规则 |
|----|------|
| 状态 | 饱食 / 心情 / 清洁 / 健康，0–100 |
| 衰减 | 按 `lastDecayAt` 轻衰减（约每 12 分钟一档）；进页时结算 |
| 亲密度 | 每 5 点亲密度进度 +1 Care Level（上限 10）；照料/抚养动作与对话均可加进度；**与 VIP 档位独立** |
| **抚养互动** | 喂食 / 玩耍 / **喝水** / 清洁 + **抚摸、陪伴散步、讲故事、喂零食、合影**；会话内多种动作连击额外亲密度；刷新 24h 亲密度保护 |
| **主动需求提醒** | 宠主动提示 **想吃 / 想玩 / 想喝**（气泡轮播 + 需求条 + 进页 Toast）；对应动作：喂食/零食→吃、玩耍/散步→玩、喝水→喝 |
| **需求 24h 满足** | `pet.needs.{eat,play,drink}.satisfiedUntil`；满足后该项安静 24h（倒计时）；到期后再次提醒。与亲密度冻结保护独立 |
| **每日抚养任务** | 抚摸 3 次 · 对话 1 次 · 喂食 2 次 → 可领亲密度礼包（非付费）；领取时另 +20 VIP XP（演示粘性奖励） |
| **24h 等级保护** | 照料/对话会刷新 `lastInteractAt`；之后 24h 为冻结保护窗。超时未互动则**亲密度 −1 / 每满 24h**（下限 **Lv.1**），**不降 VIP**。UI 显示「等级保护剩余 HH:MM:SS」；&lt;3h 警告色；降级 Toast。演示按钮「模拟经过24小时」 |
| **24h 抚养节奏（登录粘性）** | 见 §4.4b；产品目的见 §0 |
| 品种 | **菲律宾神话神兽 6 种**（`sarimanok` / `bakunawa` / `diwata` / `tigmamanukan` / `sirena` / `kapre`）；**首次进窝必选**（无自动默认）；**之后可随时更换神兽**，新神兽继承当前形态档与抚养进度；选种/换种 UI 展示当前档 + 终极形态预览 |
| **进化** | 本档 **抚养日 + 互动** 达标后可点进化；确认后 **同种 `evoTier` +1**；**展示形态 = evoTier**（不随 VIP 跳档）。换种走「更换神兽」 |
| **下一形态预览** | 舞台旁始终展示锁定/弱化的「下一形态」卡片 + 抚养日/互动进度；达终极显示「已达终极形态」 |
| VIP 形态 | 同种内 0–5 档（幼宠→银徽→管家→金甲→翼宠→冠宠）；**仅抚养进阶推进展示档**；VIP 只作可成长上限 |
| **形态成长门槛** | 每 24h 互动最多计 1 合格抚养日。幼宠→银徽 **1天/6次** · 银徽→管家 **2天/12次** · 管家→金甲 **3天/20次** · 金甲→翼宠 **5天/36次** · 翼宠→冠宠 **7天/56次** |
| **立绘风格** | 六套入库：`neutral` 中性 / `sacred` 神圣 / `cute` 可爱 / `inkgold` 墨金 / `obsidian` 玄祀 / `duskgold` 暮金；字段 `pet.artStyle`；**VIP 页可随时切换**（对应展示档，不付费）；最终留哪几套后定；更高档仍随 VIP 解锁；图集 `docs/神兽形态UI/` |
| **已达成形态抚养总结** | VIP「神兽形态」档位芯片 + 宠物窝图鉴（贴在照料区上方）：点任意档切换照料页；已达成档看抚养总结（养成门槛、本档穿着、累计日/次、亲密度）；未养成档看解锁说明。`stageHistory` 进化时写入；旧档按门槛回填。API：`getFormNurtureSummary(tier)`；演示 `demoGrowToTier(3)` |
| **终极形态奖励** | 展示档达终极（冠宠，抚养或 VIP）后，**每品种一次**打开「奖励自选」五选一（非充值）：现金 ₱88 / 现金 ₱188 / 亲密度大礼包 / 今日积分加成 / 24h 双倍亲密度 |
| 绑定 | 一员一宠：`bound` + `boundVipLevel` / `boundVipTier`；**始终绑定，无出售解绑** |
| 付费 | **宠物窝无 Deposit / 无道具付费购买**；背包仅每日免费补给 + 免费领取 |
| 今日积分 | 照料/帮养/对话加分，自然日清零；累计分保留；「今日排名」含假玩家 |
| 好友帮养 | 每日 3 次；正向轻社交；好友自带 VIP 绑定宠（六神兽混搭） |
| 对话 | 规则回复；随 **当前形态** 撒娇（外形/成长/感情）+ 品种 tone；**发送消息 +1 亲密度**；近 20 条持久化；进页主动问候 |
| **神兽口吻** | `nurture`：需求/状态低/24h 节奏将至或已到 → 气泡+快捷语促抚养。`comfort`：不需抚养时进页不催养，送 Ingat / Bathala 吉兆 / suwerte / uuwi / 敬山海树月，正向抚慰。进页 Toast 每日一次 |
| 出售 | **已取消（不做）**；无出售 Tab / 无解绑 / 无售后再养 |
| 外观 | 舞台色随形态 stage；宠物窝 **形态成长条**（抚养日/互动）；VIP 页轮播示意档位；亲密度进度条醒目展示 |
| 日补给 | 仙果×3、灵嬉球×2、净灵露×2（不覆盖多余库存）；可再点「免费+1」 |
| 购买 | **已移除付费购买**；仅免费补给 |

### 4.4b 24h 抚养节奏（登录粘性）

| 项 | 规则 |
|----|------|
| 目的 | 提高登录粘性：约每 24 小时回来深度抚养一次，参与神兽成长 |
| 时间轴 | 滚动 24h，自 `lastInteractAt`（与亲密度保护、需求满足同轴） |
| 深度抚养 | 「今日深度抚养」= 每日亲密度任务（pat×3 + chat×1 + feed×2）；完成可领奖 |
| 同访 | 允许同一次访问内多次互动；**不是**「24h 只能点一次」 |
| 状态 `status` | `fresh`（保护剩余 ≥3h）· `due_soon`（&lt;3h）· `due`（保护已到期）· `overdue`（已降级 / 亲密度已在下限） |
| 组合提醒 | 保护倒计时 + 主动需求再出现 + 深度抚养进度 + 下一形态；缺席降亲密度为留存提醒 |
| UI | 宠物窝 `#nurtureCadenceCard` + `#stageGrowthMeter`；大厅宠 HUD `lobbyCta` / 「该回来抚养了」状态行（PC + H5）；不需抚养时大厅显示神兽抚慰短句 |
| API | `getNurtureCadenceInfo()` / `getStageGrowthInfo()` / `getPetVoiceInfo()`；快照字段 `nurtureCadence` / `stageGrowth` / `voice` |

## 5. 页面说明

### 5.1 `c-end/lobby.html`

- Header：Logo、P/G、Refresh、橙色 Deposit、头像、Support
- 左侧：宠 HUD、Cashback、Bonus Mission、Promo、Daily Tasks、导航（大厅 / VIP / 宠物窝）
- 主区：蓝 Banner、Feature 卡（Watch & Earn 可点）、VIP 冲档中心（Reset / 进 VIP）
- **无**游戏厅网格、厅抽屉、一键回收
- Toast / XP 飘字 / 升级弹窗

### 5.2 `c-end/vip.html`

- 同款 Header
- 橙状态卡：宠盾牌徽章（可点进宠物窝）+ tier/level + 进度 +「去照看」按钮
- **神兽形态卡**：六套风格入库切换（中性/神圣/可爱/墨金/玄祀/暮金；最终留哪几套后定）；**更换神兽**（新神兽继承当前形态档）；点任意档看该档说明（已达成=抚养总结，未养成=解锁条件）
- 右侧：Juan365 VIP Level 轮播 + Cashback Rate
- Tabs：Benefits 六宫格（点开 Support 弹窗）、Guide（含 XP 表）、Rewards
- Demo +500 XP、Reset Demo、链宠物窝

### 5.3 `c-end/pet.html`（宠物窝 / 养成互动页）

## 7. 演示脚本

### 7.1 VIP + 宠（原路径）

1. Lobby：P≈2710、VIP3、侧栏返水；**无**厅网格  
2. 宠 HUD → 宠物窝：首次弹出新手引导（可跳过）→ 喂食/玩耍/清洁 +XP

或在控制台：`localStorage.removeItem('vip_butler_pet_v3'); location.reload()`。


### 7.2 宠物窝扩展演示（需求提醒 / 24h 满足 / 下一形态 / 进化 / 终极奖励）

1. **首次进窝** → 必选一种菲律宾神兽（含终极预览，不可跳过）→ 再走照料新手引导  
2. 打开宠物窝：见 **已绑定 VIP3**、舞台旁 **下一形态** 卡片、**想吃/想玩/想喝** 气泡与需求条（进页可 Toast）  
3. 点喂食 / 玩耍 / 喝水 → 对应需求进入 **24h 满足倒计时**（按钮红点熄灭）；亲密度上涨；对话也 + 亲密度  
4. 养满本档抚养日+互动 → 进度变为「可进化」→ 点「进化」或点下一形态卡 → **形态升一阶**（可换神兽）→ 下一形态卡刷新；更高档所需天数更长  
5. 持续进化至终极，或「演示 VIP5 终极奖励」→ **奖励自选五选一**（非充值）→ 确认领取  
6. 「演示需求提醒」可立刻让三项需求到期；「好友帮养」/「今日排名」  
7. 亲密度「进化」→ 可选保留或换其他菲律宾神兽（含终极预览）→ 形态升阶
