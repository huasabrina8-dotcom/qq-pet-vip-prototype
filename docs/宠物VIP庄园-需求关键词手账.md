## 0. 产品目的（Locked · 登录粘性）

| 关键词 | 决策 |
|--------|------|
| **目的** | **提高用户粘性** / 更频繁登录进站 |
| **手段** | 每 **24 小时**回来 **深度抚养**一次神兽，参与成长 |
| **节奏轴** | 滚动 24h（自 `lastInteractAt`），与亲密度保护窗 + 需求满足窗对齐 |
| **深度抚养** | 完成「今日深度抚养」= 每日亲密度任务：抚摸×3 + 对话×1 + 喂食×2 → 可领成长奖励 |
| **同访** | **不**限制每 24h 只点一次；同一次访问可多互动；习惯是「约每 24h 回来做一轮深度抚养」 |
| **形态进阶** | 每个形态需养够 **抚养日 + 互动** 才进下一阶段；**档越高越久**（1→2→3→5→7 天） |
| **提醒组合** | 保护窗倒计时 + 需求再出现 + 今日深度抚养进度 + 下一形态预览；缺席 24h → 亲密度降级（既有），叙事为 **留存循环**，非纯惩罚 |
| **神兽口吻** | 需要抚养时走菲律宾日常 **Taglish lambing**（sige na / please naman / miss na kita / haplos / kain na，不用中文嘛呀腔）；不需抚养时进页给 Ingat / Bathala / suwerte 抚慰（正向不凶） |
| **不做** | 不绑厅/划转/召回；不养宠付费墙；不庄园；不出售；不现实猫狗 |

## 2. 硬约束（Locked）

1. **不要游戏厅 / 平台划转 / 召回**  
   - Out of scope：厅网格、厅抽屉、转入、转出、一键回收。  
   - **明确禁止再建议**把 XP 绑回「喂厅/召回」。

2. **去掉宠物相关用户付费环节**  
   - Deposit / IAP **不作为**养宠门槛。  
   - 宠物窝无付费买道具；背包仅每日免费补给。  
   - 达成终极形态的奖励是**发给用户**的自选礼，**非充值**。

3. **不要 VIP庄园**  
   - Out of scope：地块播种、照料作物、收获、仓库、庄园订单、庄园新手引导、VIP 页庄园入口、底栏「庄园」Tab、庄园相关 Daily Tasks。  
   - **明确禁止再建议 / 再实现**庄园功能。

4. **不要出售宠物**  
   - Out of scope：出售 Tab、出售解绑、售后再领养、出售冷却/报价、虚拟金币/宝石出售结算。  
   - 管家宠 **始终绑定 VIP**；首次进窝必选菲律宾神兽；之后可随时更换神兽，新神兽继承当前形态档。  
   - **明确禁止再建议 / 再实现**出售或出售解绑。

5. **产品骨架保留**  
   - **VIP管家宠**（冲档 + 宠物窝）+ Light C（Daily Tasks）。

6. **留存循环 = 24h 抚养节奏**  
   - 目的：提高登录粘性；手段：每 24 小时回来深度抚养一次神兽参与成长。  
   - 见 §0；**禁止**改成「每 24h 只能点一次」或绑回厅/付费。

7. **形态进阶靠抚养时长，不靠 VIP 跳档**  
   - 每个形态需经过不同时长的抚养与互动才进入下一阶段；等级越高所需时间越长。  
   - VIP 只作可成长上限（未达对应 VIP 不能进更高形态），**不会**因升 VIP 直接换形态。

## 6. 宠物窝关键词清单（用户提示过 · 逐条）

以下均为对话中用户明确提过或拍板的方向（已落入原型/需求说明）：

1. **每日养宠积分与排名** — 照料/帮养/对话加今日分；自然日清零；「今日排名」可含假玩家。  
2. **帮好友养宠物** — 正向轻社交；每日次数上限（演示常见 3 次）；好友自带 VIP 绑定宠。  
3. **出售宠物细节** — **已取消（不做）**；原门槛/解绑/冷却/虚拟结算方案全部废弃。  
4. **宠物与管家 VIP 绑定** — 一员一宠：`bound` + `boundVipLevel` / `boundVipTier`；**始终绑定，无出售解绑**。  
5. **不同等级不一样的宠物形态** — 同种内幼→银徽→管家→金甲→翼→冠；**靠抚养日+互动进阶**（档越高越久）；VIP 只限制可成长上限，不跳形态。  
6. **宠物与用户对话** — 规则回复；神兽口吻随 **当前形态**；发消息可加亲密度；近条持久化。  
   - **需要抚养时**：气泡/问候/快捷语走菲律宾日常 **Taglish lambing**（sige na、please naman、miss na kita、haplos、kain na），促摸摸、喂食、陪伴、成长；不用中文「嘛呀」腔。  
   - **不需要抚养时进页**：不催养，给菲律宾信仰习惯的鼓励与情感抚慰（Ingat、Bathala 吉兆、suwerte、uuwi、敬山/海/树/月；正向，不凶、不讨债）。  
7. **用户可选种类：菲律宾神话神兽（6 种）** — **首次进窝必选**（仅神话神兽，无猫狗等现实宠物）；**之后可随时更换神兽**，新神兽升至原神兽对应形态档；无售后再养。  
   - `sarimanok` 彩羽神鸟 · Sarimanok  
   - `bakunawa` 月食神龙 · Bakunawa  
   - `diwata` 山林精灵 · Diwata  
   - `tigmamanukan` 吉兆灵鸟 · Tigmamanukan  
   - `sirena` 海之仙女 · Sirena  
   - `kapre` 树精守护神 · Kapre  
8. **二次元种类方案（已弃用备选）** — 曾出过选型包；现以菲律宾神兽目录为准，明确禁止猫狗等现实宠物；仅菲律宾神话神兽。  
9. **24 小时冻结等级** — 互动刷新保护窗；超时无互动则**降宠物亲密度等级**；**不降 VIP**。  
9b. **24h 抚养节奏（登录粘性）** — 目的提高登录频率；每 24h 深度抚养（亲密度任务）一轮；保护+需求+任务进度作留存提醒；同访可多互动。  
10. **随时更换神兽** — 宠物窝 / VIP 页「更换神兽」；新神兽继承当前形态档与抚养进度（不付费、不解绑）。  
11. **选宠时展示终极形态** — 首次选种卡 + 更换神兽 UI 均预览当前档与终极形态。  
12. **去付费，加抚养与亲密度互动** — 去掉宠内付费；强化抚摸/陪伴/零食等抚养与亲密度。  
13. **达成终极形态发放奖励 → 五种可选择奖励** — 每品种一次自选（非充值），演示常见：现金 ₱88 / ₱188 / 亲密度大礼包 / 今日积分加成 / 24h 双倍亲密度。  
14. **宠物主动提醒想吃 / 想玩 / 想喝**；对应动作满足后 **24h 持续性**安静；**持续抚养逐步进化**。  
15. **当前形态旁展示下一形态形象** — 刺激互动（抚养日/互动进度）；达终极显示已达终极。  
16. **六套立绘风格入库可切换** — 中性 / 神圣 / 可爱 / 墨金 / 玄祀 / 暮金先全部入库；VIP 页可按当前穿着档随时换风格（不付费）；最终留哪几套后定；更高档需养满且 VIP 达到上限。  
17. **神兽主动口吻** — 舞台气泡 + 进页 Toast（每日一次）+ 对话问候；需要抚养走撒娇，安稳时走抚慰。API：`getPetVoiceInfo()`（`nurture` / `comfort`）。  
18. **已达成形态的抚养总结** — 宠物窝图鉴在照料区正上方：点**任意形态档**，下面照料区换成该档页面。已养成档（非当前穿着）看抚养成就（喂食/抚摸等次数 + 神兽口吻回顾）；未养成档打开说明页。可回到当前形态继续养。VIP 形态页同样可点任意档查看。开局是幼宠；演示按钮「演示养成到金甲」便于马上点前面的档看回顾。
